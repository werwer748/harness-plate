# 회고

## 회고 1

**확인**
- check는 기록의 "남은 것" 가운데 동작의 결함이나 돌려 보지 않은 위험을 적은 줄을 보고, 통과 조건이 보는 동작에 걸리면 확인 절의 "실패"로, 걸리지 않으면 "하네스에서 걸린 것"으로 옮긴다.
  - `plugins/plate/skills/check/SKILL.md`의 description(3줄), 머리글(10줄), 절대 규칙 3(18줄), 5번(54~61줄), 판정(67줄), 확인 절 양식의 "남은 것"(104~105줄), 적는 규칙(122~126줄)을 읽음 → 모두 "결함·위험 줄이 통과 조건이 보는 동작에 걸리면 실패, 걸리지 않으면 하네스에서 걸린 것"으로 같게 적혀 있고, 절대 규칙 3이 이 줄을 판정에 넣는 것으로 든다. 판정 줄과 "실패"의 범위가 "2~5번"으로 새 5번을 센다. 통과
  - 돌리지 않음: task 머리가 check를 헤드리스로 돌리지 않는다고 정해 두었다(에이전트가 기록을 읽고 판정하는 스킬). 돌린 확인이 아니므로 통과로 세지 않고 결정대로 둔다
- retro는 `done-phase-N.md`마다 "남은 것"의 줄(부작용과 한계, 동작의 결함, 돌려 보지 않은 위험)을 모아 줄마다 문제인지 판정해 회고 절에 적는다.
  - `plugins/plate/skills/retro/SKILL.md`의 4번(77줄), 회고 절 양식의 "**남은 것**"(144~145줄), 적는 규칙(167줄)을 읽음 → 세 갈래를 모두 들고, 돌려 보지 않은 위험의 판정 방법(커밋이 바꾼 것을 읽거나 돌려 본다)이 있고, 줄마다 `phase {번호}: … → {문제 | 문제 아님} ({까닭})`을 적는 자리가 있다. 통과
  - 돌리지 않음: task 머리가 retro를 헤드리스로 돌리지 않는다고 정해 두었다. 다만 이 회고가 작업 트리의 바뀐 retro 본문을 그대로 따라 "남은 것"의 줄마다 판정을 적었다
- eval의 낱말이 바뀐 확인 절과 회고 절의 꼴과 맞는다.
  - `plugins/plate/skills/eval/SKILL.md`의 낱말 `done-phase-N.md`(29줄)와 `retro.md`(30줄)를 읽음 → 확인 절은 "남은 것", "실패", "하네스에서 걸린 것", "판정", 회고 절은 "확인", "남은 것", "문제", "판정"으로 check와 retro 양식의 항목 순서와 같다. 통과
