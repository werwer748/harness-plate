# check와 retro가 수행의 "남은 것"을 판정한다

## 목표
check는 수행 기록의 "남은 것"에서 동작의 결함이나 돌려 보지 않은 위험을 적은 줄을 판정에 넣거나 "하네스에서 걸린 것"으로 옮기고, retro는 task의 "남은 것"을 모아 줄마다 문제인지 판정해 회고 절에 적는다(#31).

## 범위 밖
- phase 스킬의 "남은 것" 규칙을 고치는 것
- check와 retro의 다른 절차를 고치는 것
- 버전과 README. `005-release`가 한다

## 완료 조건
1. check는 기록의 "남은 것" 가운데 동작의 결함이나 돌려 보지 않은 위험을 적은 줄을 보고, 통과 조건이 보는 동작에 걸리면 확인 절의 "실패"로, 걸리지 않으면 "하네스에서 걸린 것"으로 옮긴다.
   - 확인: `plugins/plate/skills/check/SKILL.md`의 frontmatter의 description, 절대 규칙 3, 절차, 확인 절의 양식, 적는 규칙을 하나씩 읽어 위의 것이 서로 어긋나지 않게 적혀 있다. 절대 규칙 3이 이 줄을 판정에 넣을 수 있는 것으로 들지 않으면 실패
   - 돌리지 않음: check는 에이전트가 기록을 읽고 판정하는 스킬이라 헤드리스로 돌리지 않는다
2. retro는 `done-phase-N.md`마다 "남은 것"의 줄(부작용과 한계, 동작의 결함, 돌려 보지 않은 위험)을 모아 줄마다 문제인지 판정해 회고 절에 적는다.
   - 확인: `plugins/plate/skills/retro/SKILL.md`의 4번, 회고 절의 양식, 적는 규칙을 하나씩 읽어 위의 것이 적혀 있다. 돌려 보지 않은 위험이 빠졌거나 회고 절에 줄마다의 판정을 적는 자리가 없으면 실패
   - 돌리지 않음: retro는 에이전트가 기록을 읽고 판정하는 스킬이라 헤드리스로 돌리지 않는다
3. eval의 낱말이 바뀐 확인 절과 회고 절의 꼴과 맞는다.
   - 확인: `plugins/plate/skills/eval/SKILL.md`의 낱말 `done-phase-N.md`와 `retro.md`를 읽어 바뀐 두 절의 항목과 어긋나지 않는다

## 결정
- check는 "남은 것"의 결함·위험 줄이 통과 조건이 보는 동작에 걸리면 실패로, 걸리지 않으면 "하네스에서 걸린 것"으로 옮긴다. 이유: 적힌 것만 판정에 넣는다는 check의 규칙을 지키면서 결함을 그 자리에서 잡는다
