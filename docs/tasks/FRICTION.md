# FRICTION

- `001-tools-doc` 문제: phase 1 통과 조건(task 머리 완료 조건 4와 같은 꼴)의 grep `사용량.*TOOLS\.md|TOOLS\.md.*사용량`이 규칙의 부재를 설명하는 `docs/ARCHITECTURE.md`의 테스트 설명 줄까지 잡아, 수행하는 쪽이 설명 글을 "맥락 문서 커밋 규칙이 없고"로 돌려 적어 피했다. plan이 "어떤 줄이 없다"를 grep으로 확인할 때 그 부재를 설명하는 줄(테스트 설명, 결정 줄)에도 걸리는지 보지 않는다
- `002-run-rules` 문제: phase 1 수행이 `python3 - <<'EOF'` heredoc으로 스킬 본문을 고치려다 stdin의 한글이 `SyntaxError: Non-UTF-8 code starting with '\xec'`로 깨져 Edit 도구와 `python3 -c`로 바꿨다(`done-phase-1.md`의 "하네스에서 걸린 것"). 한글 본문을 셸로 고치는 법이 계획의 TODO나 맥락 문서에 없다
- `002-run-rules` 멈춤: 회고 에이전트가 API 오류(ENOTFOUND)로 결과 없이 끊겨 사용자에게 물었고 답은 재시도였다(`RUNLOG.md`의 `멈춤` 줄)
- `002-run-rules` 스킬 후보: 제목 넘기는 법을 가짜 `gh`로 돌리는 장면(`<임시>/bin/gh`, `<임시>/run.sh`, `grep -cxF`, `pwned` 없음)을 phase 1과 phase 3의 수행·확인이 저마다 손으로 다시 짰다. 이 장면을 `tests/`의 단위 테스트나 스크립트로 두면 phase마다 같은 셸 묶음을 짜는 일이 줄어든다
- `002-run-rules` 경계 밖: 보안-1이 든 "밖의 사람이 댓글 하나로 이슈 올림을 막는다"는 길이 남는다. run "이슈를 올린다" 2번이 본문이나 댓글에 tasks 이름이 있는지로 올리지 않기를 정해서다. tasks 결정이 보고서의 고치는 방향(데이터로만 본다는 줄)을 따르게 해 약속 밖에 두었다. 2번이 이슈 작성자나 댓글 작성자를 plate를 돌린 계정으로 좁힐지 볼 까닭이 있다
- `002-run-rules` 경계 밖: run 1번은 1항에서 커밋하지 않은 계획 파일을 지금 브랜치에 커밋한 뒤 3항에서 이미 있는 `tasks/<이름>`으로 `git switch`한다. 그 브랜치에 계획 커밋이 없으면 계획이 tasks 브랜치에 들지 않는다(기본 브랜치에서 시작할 때도, 이번에 더한 다른 브랜치의 승인 갈래도 같다). 계획 커밋을 브랜치를 바꾼 뒤로 미룰지 볼 까닭이 있다
- `003-plan-rules` 없음
- `004-fixes` 문제: task 머리 완료 조건 1이 "본문의 `awk`·`grep` 명령을 돌리지 않는다"를 문제로 들면서 고침과 확인에는 `awk` 테스트와 가짜 `gh` 테스트만 적어, run 3번 "멈춘다" 앞의 `grep '^- 물음 | 멈춤 | …' docs/tasks/RUNLOG.md | tail -n 1` 명령은 여전히 돌리는 테스트가 없다. plan이 review 소스 문제를 고침 task의 완료 조건으로 옮길 때 문제의 글과 확인이 보는 범위가 같은지 보지 않는다
- `004-fixes` 문제: task 머리 완료 조건 1의 "본문의 `awk` 패턴이나 `'\''` 치환 글을 바꾼 사본에서 그 테스트가 실패한다"에 돌릴 명령(무엇을 무엇으로 바꾸고 어떤 사본에서 돌리는지)이 없어, phase 1의 수행·확인(`done-phase-1.md` 확인 1 "하네스에서 걸린 것")과 이 회고가 저마다 사본과 바꿀 글을 손으로 짰다. plan의 적는 규칙(**조건**)이 바꾼 사본으로 보는 확인에 바꿀 글과 사본의 꼴을 적게 하지 않는다
- `004-fixes` 문제: heredoc 줄에 붙일 "확인한 버전"의 출처가 phase 1의 읽을 것에 없어, 수행하는 쪽이 읽을 것 밖의 `docs/tasks/002-run-rules/done-phase-1.md`를 `grep`하고 `git log`로 시각을 봤다(`done-phase-1.md` "하네스에서 걸린 것"). plan이 도구 동작을 버전과 함께 적게 하는 TODO에 그 버전을 어디서 얻는지 적지 않는다
