**확인**
- plan의 적는 규칙 "phase의 파일"의 읽을 것 줄과 "조건"에 저마다, 같은 task의 앞 phase나 앞 task가 고칠 파일은 줄 번호 대신 절 이름이나 항목 이름으로 가리킨다는 줄이 있다. 6번의 초안 전 점검에는 줄 번호로 가리킨 읽을 것과 확인이 앞에서 고칠 파일을 가리키지 않는지, 같은 사실을 잇는 이웃 줄을 빠뜨리지 않는지 보는 줄이 있다.
  - `plugins/plate/skills/plan/SKILL.md`의 "phase의 파일"(읽을 것 줄), "조건", 6번을 하나씩 읽음 → 읽을 것 줄에 "같은 task의 앞 phase나 앞 task가 고칠 파일은 줄 번호 대신 절 이름이나 항목 이름으로 가리킨다"가, "조건"에 같은 뜻의 확인 줄이, 6번에 앞에서 고칠 파일을 줄 번호로 가리키지 않는지와 이웃 줄을 빠뜨리지 않는지 보는 점검 줄이 있다. 통과
  - 돌리지 않음 줄(plan은 묻고 승인받는 스킬) → 확인이 아니어서 돌리지 않음. 해당 없음
- plan의 "조건"에 동작을 바꾸는 완료 조건에는 돌리는 확인(시험 저장소나 `mktemp -d`)을 두고, 돌릴 수 없으면 `- 돌리지 않음: {까닭}` 줄을 둔다는 줄이 있다. 6번의 점검과 양식(tasks 머리, task 머리)의 완료 조건도 그와 맞는다.
  - 같은 파일의 "조건", 6번, 양식의 tasks 머리 완료 조건, task 머리 완료 조건을 하나씩 읽음 → "조건"에 돌리는 확인과 `돌리지 않음` 줄 규칙(확인 줄을 대신하지 않는다는 글 포함)이, 6번에 완료 조건마다 돌리는 확인이나 그 줄이 있는지 보는 점검이, 두 양식의 `확인:` 줄 아래에 돌릴 수 없을 때만 두는 `- 돌리지 않음: {…}` 줄이 있다. 네 곳이 맞는다. 통과
