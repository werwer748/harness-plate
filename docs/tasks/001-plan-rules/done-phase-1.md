- 6번의 초안 전 점검에 두 줄이 더해졌다: 줄 번호로 가리킨 읽을 것과 확인이 앞에서 고칠 파일을 가리키지 않는지, 이웃 줄을 빠뜨리지 않는지 본다. 동작을 바꾸는 완료 조건마다 돌려 보는 확인이나 `돌리지 않음` 줄이 있는지 본다 (`plugins/plate/skills/plan/SKILL.md`)
