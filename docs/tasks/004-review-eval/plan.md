# review의 테스트 적절성과 eval의 정해 둔 물음을 고친다

## 목표
review가 결과물인 마크다운만 바꾼 tasks의 테스트 적절성을 완료 조건의 확인으로 매기고(#27), eval이 run의 정해 둔 물음을 멈춤으로 세지 않는다(#28).

## 범위 밖
- 코드 파일이 하나라도 바뀐 tasks의 테스트 적절성 칸을 고치는 것
- run의 물은 자리 목록을 고치는 것. `003-base-branch`가 했다
- 버전과 README. `005-release`가 한다

## 완료 조건
1. review는 바뀐 코드 파일이 결과물인 마크다운뿐이면 테스트 적절성을 tasks 머리와 task 머리의 완료 조건이 바뀐 동작마다 돌려 보는 확인을 두었는지로 매기고, 등급표에 그 경우의 칸이 있다. 읽기만 하는 확인과 `- 돌리지 않음: {까닭}` 줄은 돌려 보는 확인보다 낮은 칸에 든다. PR 모드에서는 이 경우 판단 못함이다.
   - 확인: `plugins/plate/skills/review/SKILL.md`의 4번의 표, 5번의 등급표와 그 아래 줄, PR 모드 절을 하나씩 읽어 위의 것이 적혀 있다. 그 경우의 칸이 A~E로 나뉘어 있지 않거나 `돌리지 않음` 줄이 돌려 보는 확인과 같은 칸에 들면 실패
   - 돌리지 않음: review는 에이전트가 판단하는 스킬이라 헤드리스로 돌리지 않는다
2. eval의 낱말 "정해 둔 물음"은 run의 `RUNLOG.md` 절의 물은 자리 가운데 `멈춤` 말고 모두이고, "멈춤"은 물은 자리가 `멈춤`인 줄이다. 3번의 사람 개입률과 retro 5번의 "멈춤"도 그와 맞는다.
   - 확인: `plugins/plate/skills/run/SKILL.md`의 `RUNLOG.md` 절의 물은 자리 목록과 `plugins/plate/skills/eval/SKILL.md`의 낱말 "정해 둔 물음"을 견줘, `멈춤`을 뺀 목록이 같다. 다르면 실패
   - 확인: eval 3번의 사람 개입률과 `plugins/plate/skills/retro/SKILL.md` 5번의 "멈춤" 줄을 읽어 eval의 낱말과 어긋나지 않는다
   - 돌리지 않음: eval은 에이전트가 기록을 세는 스킬이라 헤드리스로 돌리지 않는다
3. `docs/ADR.md`의 ADR-024가 바뀐 테스트 적절성과 어긋나지 않는다.
   - 확인: ADR-024의 트레이드오프에서 테스트 적절성을 말하는 문장을 읽어, 결과물인 마크다운만 바꾼 tasks의 경우와 어긋나지 않는다
4. tasks 완료 조건 3과 4 가운데 이 task가 고친 파일에 걸리는 것이 그대로 참이다.
   - 확인: `plugins/plate/skills/retro/SKILL.md`의 4번과 회고 절의 양식을 읽어, `done-phase-N.md`마다 "남은 것"의 줄(부작용과 한계, 동작의 결함, 돌려 보지 않은 위험)을 모아 줄마다 문제인지 판정해 회고 절에 적는다는 것이 있다
   - 확인: eval의 낱말 `done-phase-N.md`와 `retro.md`를 읽어 check의 확인 절과 retro의 회고 절의 항목과 어긋나지 않는다
   - 확인: review의 낱말 "갈라진 곳"을 읽어 로컬 기본 브랜치의 `git merge-base <기본 브랜치> HEAD`라고 적는다

## 결정
- 결과물인 마크다운만 바꾼 tasks의 테스트 적절성은 완료 조건이 바뀐 동작마다 돌려 보는 확인을 두었는지로 매긴다. 이유: 등급이 하네스를 고칠지 정하는 데 쓰이고 #32와 맞물린다
- 돌릴 수 없는 완료 조건은 확인 줄과 따로 `- 돌리지 않음: {까닭}` 줄을 둔다(plan의 규칙). review는 이 줄을 테스트 적절성의 근거로 읽는다. 이유: check와 retro의 "돌리지 않은 확인은 통과가 아니다"와 부딪히지 않는다
- 정해 둔 물음은 run의 `RUNLOG.md` 절의 물은 자리 가운데 `멈춤` 말고 모두다. 지금 목록은 `실행 방식`, `커밋하지 않은 변경`, `기본 브랜치`, `고칠 phase`, `다음 task`, `멈춤`, `고칠지`다. 이유: 이슈가 제안한 안이고, run이 목록을 바꾸면 eval이 따라간다
