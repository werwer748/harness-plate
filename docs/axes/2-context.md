# 2축. 맥락 설계 — 설정 상속 / CLAUDE.md / Progressive Disclosure

> [HANDOFF.md](../../HANDOFF.md)에서 나눈 6축 문서다. 표시(기본값·결정·보류·남음)의 뜻과 기호(J, R, M1–M4)는 HANDOFF.md에 있다. 결정을 확정하거나 바꾸면 아래 표와 [결정 기록](../decisions.md)을 함께 고친다.

**다루는 질문**: 에이전트가 언제, 무엇을, 얼마나 알고 시작하는가.

| | 레퍼런스와 내 자산 |
|---|---|
| 설정 상속 | 층위: managed > CLI > local > project > user settings, 그리고 plugin<br>전역 `~/.claude/settings.json`에는 iTerm 상태 훅만 있다. 전역 `~/.claude/CLAUDE.md`는 2026-10-01에 생겼다(작업 원칙 4개와 영어 응답 규칙 2개)<br>격리 수단(`--setting-sources`, `--strict-mcp-config`)은 M3에서 확인했다 |
| CLAUDE.md | **J**: CRITICAL 규칙을 직접 적는 규칙형<br>**R**: 포인터형. 호출 조건과 변경 이력만 둔다 |
| Progressive Disclosure | **J**: `docs/*.md` 전체를 매 step에 주입한다(비용이 커지고 요약이 누적된다)<br>**R**: 스킬을 3층으로 나눈다. 메타데이터 약 100단어 / 본문 500줄 미만 / references는 필요할 때만 읽는다<br>**M2**: `paths:` 규칙을 지연 로드하고, CLAUDE.md 색인 표를 두고, `check.sh`로 lint한다 |

**결정과 처리**

| # | 결정 | 처리 |
|---|---|---|
| 1 | 전역 `~/.claude/CLAUDE.md`에 넣을 것(모든 프로젝트 공통 작업 방식)과 넣지 않을 것 | **상태가 바뀌었다.** 전역 파일이 생겼고 "단순함 우선", "검증 가능한 목표" 같은 공통 작업 원칙이 이미 들어 있다. **결정**: 하네스 규칙을 여기에 더 넣지 않는다. 같은 실수가 여러 프로젝트에서 반복된 근거가 있을 때만 추가한다 |
| 2 | 프로젝트 `CLAUDE.md`: 규칙형 / 포인터형 / 색인형(규칙 본문은 `rules/`) 중 무엇으로 할지 | **기본값**: 지금 적용되는 규칙만 짧게 둔다(200줄 미만). 변경 이력은 넣지 않고 git log나 CHANGELOG에 둔다. 길어지면 `rules/`와 `paths:`로 옮긴다 |
| 3 | `docs/`(PRD·ARCH·ADR) 세트를 채택할지, 그리고 주입할지 참조만 할지 | **결정**(2026-10-05): 세트는 `docs/PRD.md`·`docs/ARCHITECTURE.md`·`docs/ADR.md` 3종이고 스킬 `/plate:init`(`plugins/plate/skills/init/SKILL.md`)이 처음 만든다. 코드가 있으면 저장소에서 확인한 내용만 채우고, 빈 프로젝트에는 양식을 넣는다. 주입하지 않고 `CLAUDE.md`의 포인터 절로 가리킨다. 스킬은 자연어 요청으로도 호출된다(설명 한 줄이 매 세션에 실린다). 세트를 둘지는 프로젝트마다 정한다(스킬을 부른 프로젝트에만 생긴다) |
| 4 | 컨텍스트 예산 상한(줄 수·크기)과 이를 기계로 검사할지 | **보류.** 규칙이 무시되는 일이 반복되면 정한다. 그 전에는 `/context`와 `/doctor`로 본다 |
| 5 | 메모리와 규칙 문서의 역할 분담 | **결정**: 새 규칙을 만들지 않고 플랫폼 기본값을 따른다(메모리에는 사용자 선호, 작업 방식 피드백, 진행 상태, 외부 자료 위치. 레포가 이미 기록하는 것은 넣지 않는다). 제약 하나만 기억한다: 메모리는 이 컴퓨터에만 있고 서브에이전트에 전달되지 않으므로, 서브에이전트나 다른 컴퓨터가 알아야 하는 내용은 규칙 문서에 둔다. 둘이 어긋나 문제가 되면 다시 연다 |
| 6 | 하네스의 절대 규칙(작업 헌법)을 어디에 두고 어떻게 싣는가 | **결정**(2026-10-06): `plugins/plate/AGENTS.md` 한 파일에 두고 SessionStart 훅(`plugins/plate/hooks/constitution.sh`)이 세션마다 싣는다(새 세션, 재개, `/clear`, 압축 뒤). plate를 설치한 모든 프로젝트에 적용되고, 규칙을 더하면 플러그인 업데이트로 퍼진다. 처음에는 뼈대만 두고 사용자가 확인한 규칙을 하나씩 더한다. 메인 세션에만 실리므로 서브에이전트가 지켜야 할 규칙이 생기면 `SubagentStart` 훅을 더한다. 훅 출력의 상한은 10,000자다(`tests/test-constitution.sh`가 확인한다) |
