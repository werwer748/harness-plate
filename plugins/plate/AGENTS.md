# plate 작업 헌법

plate를 설치한 프로젝트에서 일하는 에이전트가 예외 없이 지키는 규칙이다. plate가 세션을 시작할 때마다 이 파일을 그대로 싣는다.

## 규칙

(아직 없다)

## 규칙을 고칠 때

- 이 파일은 harness-plate 레포의 `plugins/plate/AGENTS.md`에서만 고친다.
- 사용자가 확인한 규칙만 넣는다. 에이전트는 제안만 한다.
- 지금 적용되는 규칙만 적는다. 할 일, 진행 상태, 변경 이력은 적지 않는다.
- 근거와 날짜는 harness-plate 레포의 `docs/decisions.md`에 적는다.
